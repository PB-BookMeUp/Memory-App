# Vision

An app like MemoryOS, built for Indian adults in the 40 to 60 age range. It has to be engaging, relatable, and sticky.

## Decided

- Content: memory techniques as the core, with topic packs to apply them to.
- Daily hooks: staying mentally sharp, and family and culture.
- Language: Priya speaks Indian English and Hinglish. Captions match her words. No long Hindi text to read.
- Audio first: the coach speaks every screen, like MemoryOS. Reading is optional.
- Format: bite-sized lessons and quizzes.
- Budget: none, so the first version must use free tools only.

## Open

- Platform (a mobile web app is the free option, to be confirmed)
- Who the first test users are
- Lesson and quiz structure
- Streaks, rewards, and reminders
- Name and look

## First user

The founder's mum. Uses WhatsApp, not app savvy, knows basic English.

What this means for the build:

- Big text, big buttons, one thing per screen
- No account or password to start
- Opens from a link shared on WhatsApp, can be added to the home screen
- Simple English with Hinglish flavour, no jargon
- Lessons under 3 minutes

## Daily loop

One 2 minute technique lesson, then a 5 question quiz that uses it. Under 5 minutes total.

First topic pack: daily life (shopping lists, phone numbers, where she kept things).

What brings her back: a brain score that goes up over weeks, like a fitness score.
